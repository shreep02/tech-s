# Developer Portfolio

A lightweight Angular portfolio for showcasing software testing, automation, and web development experience.

## Development

Install dependencies and start the local server:

```bash
npm install
npm start
```

Open `http://localhost:4200/` in the browser.

## Build

```bash
npm run build
```

## Notes

This project is designed as a personal portfolio and can be extended with additional case studies, real project details, and contact workflows as needed.
